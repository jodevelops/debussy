EDTF-Konvertierung

Erst im Daten-Tab CSV laden.

EDTF-Regeln (LOC Standard)

"1920" → 1920
"17.05.1923" → 1923-05-17
"ca. 1920" → 1920~
"um 1850" → 1850~
"1920?" → 1920?
"vor 1900" → ../1900
"nach 1950" → 1950/..
"1920-1930" → 1920/1930
"1920er" → 192X
"19. Jh." → 18XX
"undatiert" → (leer)
